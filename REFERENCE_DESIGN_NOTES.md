# freia — reference-inspired Swiss design pass

The supplied Fri28Aug code was used as structural inspiration for the modular design system. The freia content and visual identity remain unchanged.

Applied principles:
- 12-column desktop, 6-column tablet and 4-column phone grids
- 8 px baseline and fluid margins/gutters
- 1800 px maximum editorial field
- brand in the left grid field; navigation in the right grid field
- section headings start deeper in the grid to create controlled asymmetry
- interactive figures use a centered 10-column field on desktop
- fluid `clamp()` typography and spacing
- breakpoint-specific composition rather than uniform shrinking
- keyboard focus and reduced-motion support
